# HangLab (행랩)

클라이밍 보드 트레이닝 기록 앱. 보드 이미지에서 홀드를 골라 매달린 시간을 세트로 기록한다.

## MVP 범위

- 보드: Beastmaker 1000, 2000
- 보드 이미지에서 홀드 선택 → 매달린 시간(초) 기록 → 세트 기록
- 탭: 스톱워치 · 타이머 · 인터벌. 마지막 탭 저장
- 스톱워치·타이머: 시작하면 바로 매달리기(준비 카운트다운 없음). 타이머는 목표 시간에서 줄어들어 0초에 자동 기록, 중간 정지는 실제 시간 기록. 휴식 중 큰 숫자는 스톱워치면 휴식 경과, 타이머면 다음 목표(휴식 경과는 위에 작게)
- 인터벌: 세로 다이얼(눈금 포함, 단위 s·회는 가운데 칸 옆에 고정)로 운동 시간·휴식 시간(1~600s)·세트 수(1~30회) 설정, 기기에 저장. 처음에만 3초 준비 후 운동(주황)·휴식(파랑) 시간이 번갈아 줄어들고, 마지막 운동 뒤 휴식 없이 끝남. 진행 중에는 왼쪽 위 운동/휴식, 오른쪽 위 세트 n/n(휴식은 방금 끝낸 세트), 가운데 남은 시간 숫자만 표시. 운동이 끝날 때마다 세트로 기록(중간 정지는 실제 시간), 앱이 잠시 멈췄다 돌아와도 끝난 운동은 모두 기록
- 선택 유지: 앱을 다시 열면 마지막 보드·양손/한 손·홀드가 골라진 상태
- 타이머 목표 시간: 다이얼을 끌거나 시계 숫자를 두 번 탭해 초 단위 입력(1초~10분). 다이얼 눈금은 60초까지 1초, 3분까지 5초, 10분까지 15초 간격. 홀드별로 기기에 저장하고, 저장 안 된 홀드는 마지막 목표로 시작
- 세트 삭제: 오늘 세트를 탭하면 삭제 버튼

## 지표

- 볼륨: 같은 홀드(보드·양손/한 손·홀드 쌍) 세트의 매달린 시간 합
- 주간 증감: 이번 주(월요일 0시 시작) 볼륨 − 지난주 볼륨
- 최장: 그 홀드의 전체 기간 단일 세트 최장 시간
- 선택한 홀드 아래에 이번 주 볼륨·증감·최장, 기록 시트에 주간 합계와 최근 8주 막대·홀드별 카드

## 이후 범위

- 세션 자동 기록, 세트 수 관리
- 소리 알림, 휴식 카운트다운
- 체육관 캠퍼스보드 등 보드 추가

## 실행

- `npm install` 후 `npx expo start`
- iPhone: App Store에서 Expo Go 설치 → 터미널 QR을 카메라로 스캔. 맥과 같은 Wi-Fi 필요, 다른 네트워크면 `npx expo start --tunnel`
- 웹: `npx expo start --web`

## 검증

- `npx tsc --noEmit`, `npm run lint`
- `npm run e2e:web`: 웹 서버가 떠 있는 상태에서 시스템 Chrome으로 시나리오(보드 전환, 대칭 선택, 타이머 기록, 새로고침 후 기록·선택 유지, 홀드 지표·주 경계, 기록 시트, 세트 삭제, 타이머·목표 시간 저장, 브라우저 시계를 돌린 10분 이상 기록, 인터벌 단계·색·기록·중간 정지·멈춤 복귀, 이전 설정 형식 이전)를 돌린다. 지표 시나리오는 이번 주 월요일 기준 fixture를 저장소에 넣어 확인한다. 결과와 캡처는 `e2e-results/`

## 디렉토리

- `App.tsx`, `src/`: 앱 화면, 보드 SVG, 타이머, 기기 내 저장
- `data/boards/`: 보드별 홀드 데이터(JSON)
- `scripts/`: 검증 스크립트
- `docs/reference/app/`: 레퍼런스 앱 조사와 스크린샷
- `docs/reference/boards/`: 홀드 데이터 출처와 불확실 항목
