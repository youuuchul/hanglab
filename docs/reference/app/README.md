## 사용자 사용 앱: 짐워크(Gymwork)

- 사용자 확인(2026-11-05): 처음 언급한 'gtmworks'는 짐워크(Gymwork, kr 평점 4.66, 3,505건).
- 사용자가 쓰는 기능: 총 e1RM, 총 볼륨, 세션 자동기록, 세트 수 관리, 시작/휴식 카운트, 운동별 주간 +/- 기록.
- 스토어 설명에서 확인된 것: 세트 수·순서 커스텀 루틴, 세트 완료 후 자동 휴식 타이머, 부위별 볼륨과 RPE 그래프, 볼륨 랭킹, 이전 기록 기반 무게/횟수 추천.

### Beastmaker Training App (공식)

- 링크: https://apkpure.com/beastmaker-training-app/com.beastmaker.beastmaker (Android 3.2.1, 2019-10 최종 업데이트, 개발사 Beastmaker Ltd)
- iOS: 구 App Store id563826086 이 us/gb/kr/de Lookup에서 조회되지 않음. 현재 제공 여부 미확인. Play 공식 페이지도 404.
- 핵심 기능
  - 1000/2000 시리즈 선택 후 사전 작성 워크아웃 목록(Beasty 5A ~ 7B 등) 제공
  - 2000 전용 슬로퍼/포켓/크림프 워크아웃
  - 세트·행 횟수 조정, 맞춤 타이머, 행 시간 기록(휴식 중 기록 버튼)
  - 워크아웃 평가(Workout Ratings)로 진행도 추적
- 가져올 점
  - 타이머 화면의 정보 구성: 남은 행 횟수, 휴식/준비 상태, 누적 행 시간(Total hang time)
  - 시리즈(1000/2000)를 첫 선택 단계로 두는 진입 구조
- 피할 점
  - 보드 사진이 장식이고 홀드는 워크아웃 이름("4 fingers open")으로만 지정된다. 홀드 선택 UI가 없다. 이것이 우리 앱의 차별점.
  - 2019년 이후 갱신 없음, UI 노후

#### 사용자 캡처에서 확인한 화면 구성

- 상단 바: 운동 시간(경과), 완료 버튼, 완료 체크된 세트 기준 총 kg·kcal·세트 수. 체크 전이라 0으로 표시.
- 종목 카드 부제가 두 상태로 바뀐다: '1,740kg (+1,040)'(종목 볼륨과 증감), 'e1RM 62.1kg'.
- 볼륨 1,740kg은 세트 1~4 합(50x6 + 50x8 + 40x12 + 40x14)과 일치. 증감 비교 기준(직전 세션/주간)은 화면만으로 판별 불가, 사용자 설명은 주간.
- e1RM 62.1kg은 Brzycki 공식(무게 x 36 / (37 - 횟수))의 50kg x 8회 값 62.07과 일치. 40kg x 14회(62.6)는 반영되지 않아 고반복 세트를 제외하는 것으로 보인다. 공식은 추정.
- 세트 행: 번호, 무게, 횟수, 완료 체크. 위에 세트 수 -/+ 스테퍼, 불러오기(이전 기록), 전체 완료 체크.
- 하단 고정 바: 세트 타이머 00:00과 재생 버튼. 종목 추가는 떠 있는 버튼.

## MVP에 반영할 패턴

- 보드 사진 위 원형 오버레이로 홀드 선택, 선택 상태는 색으로 구분(Tension Board). Beastmaker 공식 앱에는 없는 기능이므로 핵심 차별점으로 둔다.
- 선택한 홀드 + 매달린 시간(초)을 한 세트 레코드로 저장하고, 세트 행에 지난 세션 값을 같이 표시(Hevy, Strong).
- 한 화면에서 타이머 모드와 스톱워치 모드를 전환: 카운트다운(행/휴식, REP x/y, SET x/y, UP NEXT)은 Crimpd/Beastmaker, 시간 측정형 세트는 Strong의 Duration 유형 참고.
- 타이머 화면은 큰 숫자, 구간별 색 구분, 잠금 버튼, 백그라운드/화면 꺼짐 유지, 소리 알림(Seconds). 행 시간 누적값 상시 표시(Beastmaker).
- 세트 완료 체크 시 휴식 카운트다운 자동 시작(짐워크, Hevy, Strong). 세션은 첫 세트 기록 시 자동 생성, 헤더에 경과 시간과 총 볼륨 표시.
- 운동(홀드)별 차트는 볼륨, e1RM(또는 최대 매달림 시간) 두 축 + PR 마커(Strong). 주간 +/- 증감은 짐워크처럼 종목(홀드) 카드 부제에 '총량 (+증감)'으로 두고 대표 지표와 전환.
- 세션 종료 시 RPE와 메모 입력(hang!, Hevy), 달력/streak으로 일관성 표시(Hevy).
- 진입 구조는 보드 종류(1000/2000) 선택 -> 활동 타일(Crimp Log). 보드 종류를 데이터로 분리해 캠퍼스보드 등으로 확장(Kilter/Tension의 보드 목록 개념).
